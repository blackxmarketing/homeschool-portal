# The game: Lumina

The kid side of the portal is a pixel-art adventure. Learning is the gameplay:
every quest is a real lesson, and the world only comes back to life when the
kid actually masters things. Agreed with the parents on 2026-10-05.

## The story

Lumina has gone dark. Each land lost its light. The kid is a Lightkeeper:
mastering lessons relights beacons, and each beacon brings color, life and new
paths back to its part of the world.

## The world

- **Home village** (the hub): the hero's house, the quest board, the shop,
  the family beacon.
- **Math Mountains**: the seven math worlds (Number Forge, Fraction Falls,
  Decimal Docks, Ratio Market, Algebra Arena, Geometry Peaks, Data Lab).
- **Science Isles** (Science course), **History Kingdom** (History & Civics),
  **Wordsmith Woods** (Writing), **Merchant Harbor** (Money and Business),
  **Leaders' Summit** (Leadership).

## How learning maps to the game

| Game | Learning |
|---|---|
| Land | A course (or the math strand worlds) |
| Main quest | A lesson |
| Quest objectives | The lesson's teaching parts, then the challenge |
| Boss challenge | "Show what you know" (mastery check) |
| Field mission | The lesson's real-world task (parent approves) |
| Side quests | Brain benders, creative quests, real-world missions, and "rekindle a fading beacon" reviews (spaced review) |
| Daily quests | The 2-hour day rings |
| Beacon lit | Lesson mastered: that part of the map turns from grey to color |
| Coins | Earned from stars, quests and streaks |

## Heroes and rewards

- Each kid designs a pixel hero (skin, hair, outfit, hat, companion pet) who
  walks the map. Gear and pets are bought with coins and are just for show.
- Parents set real-life rewards (e.g. "pick Friday's movie"); kids request them
  with coins and a parent approves.
- Siblings: separate adventures, shared weekly family quests, and visiting each
  other's hero. No leaderboards or rankings.

## Looks by grade

| Grades | Feel |
|---|---|
| 4–5 | Bright, chunky pixels, big buttons, more voice and pictures |
| 6–8 | Classic 16-bit adventure |
| 9–12 | Moodier, more detailed pixel art, cleaner interface, less hand-holding |

## Phases

- **A** — Pixel world map, lands with quest locations, quest log, hero
  creator, coins, grade-band looks. *(built)*
- **B** — Shop (gear, pets), parents' real-rewards catalog and approvals,
  family quests, visiting a sibling's hero.
- **C** — Lessons as game scenes (each challenge type gets a game skin), a boss
  challenge for mastery, field missions. *(built)*
- **D** — Lesson sets for grades 4–5 and 9–12.

All pixel art is drawn in code (`src/lib/pixel/`), so it's free to change and
consistent everywhere.
